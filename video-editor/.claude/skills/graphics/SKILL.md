# Graphics and b-roll

Plan first, then build, then check.

1. **Plan:** read the transcript, list every graphic with its start word and end word. Write it to `work/<clip>/graphics_plan.md`.
2. **Build:** each graphic is its own transparent layer (HyperFrames → ProRes 4444 / WebM with alpha, or a Final Cut title). One file per graphic.
3. **Place** on the cut timeline at the word's timestamp (from the remapped words) and **check** frames.

Per style:
- **A:** listing thumbnail grid (3x2) at intro, then one rounded portrait card per point; section labels.
- **C:** b-roll every 1–4s, one in-scene stylized word, one purple→pink gradient bumper.
- **D:** subtitle line under the band, black text-only beats, B&W section.
- **E:** night b-roll hook, rapid backstory cutaways (0.5–1s), one PiP selfie, @handle watermark.

B-roll comes from the shoot folder the owner points to. Ask once if none is given.
